# 30 Days of Python

A hands-on Python learning repository with lessons, example programs, practice files, datasets, and supporting resources. The material progresses from Python basics to topics such as web scraping, data analysis, APIs, and MongoDB.

## Contents

The repository includes:

- **Lesson notes** in Markdown, covering topics from variables and strings through APIs and web development.
- **Example Python programs** for experimenting with concepts introduced in the lessons.
- **Sample data** in formats such as CSV, JSON, XML, and plain text.
- **Images and other assets** used by the lessons.
- **A small web project**, with files such as `app.py`, HTML pages, CSS, and a `Procfile`.
- **A `requirements.txt` file** listing project dependencies.

Some lessons have translated versions, including files marked with `_cn` and Korean-language resources such as `_ko` files.

## Getting started

You will need Python 3. The examples are intended to be explored one lesson at a time.

1. Clone or download the repository.
2. Open a terminal in the repository directory.
3. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   On macOS or Linux:

   ```bash
   source .venv/bin/activate
   ```

   On Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

4. If you want to install the dependencies listed for the project, run:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Open a lesson Markdown file and work through its examples. Run individual Python scripts from the terminal, for example:

   ```bash
   python day-3.py
   ```

   The exact script name depends on the lesson. Check the file before running it; not every Python file is a standalone program.

## Working with the examples and data

The repository includes files such as `countries_data.json`, `cats.json`, `hacker_news.csv`, `weight-height.csv`, and several speech and text files. These support exercises involving file handling, data processing, statistics, Pandas, or web scraping.

When a lesson reads a local file, run its script from the appropriate working directory so the file path resolves. Some exercises may also require internet access, external services, or credentials. Review the relevant lesson and code before running those examples, and do not commit passwords, API keys, or database connection strings.

Files such as `result.csv`, `result.html`, and `scrapped_data.json` may be used as example outputs or generated by exercises. Avoid overwriting data you want to keep.

## Web project

The repository contains web-related files, including `app.py`, HTML pages, `main.css`, and a `Procfile`. These appear to support the web-development lessons. To determine how to run the application, inspect `app.py` and the relevant lesson instructions; the required command and configuration depend on the code and installed dependencies.

## Suggested learning approach

- Follow the lessons in order, especially if you are new to Python.
- Type and modify examples rather than only reading them.
- Use the supplied scripts and datasets for practice.
- Keep your experiments separate from the original lesson files when possible.
- If an example fails, check the Python version, current working directory, dependencies, and any service-specific setup described in the lesson.

## Notes

This repository contains instructional material and examples; it is not necessarily a single application that can be run all at once. Dependencies and setup requirements can vary by lesson. Review the relevant Markdown file before installing optional tools or running code that connects to external services.
