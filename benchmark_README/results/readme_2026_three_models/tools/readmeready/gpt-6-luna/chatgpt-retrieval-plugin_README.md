# chatgpt-retrieval-plugin<h2>Description</h2>

<p>The ChatGPT Retrieval Plugin lets you search personal or work documents using natural-language queries. It provides an API for storing and retrieving document chunks, so relevant information can be found and supplied to ChatGPT.</p>
<h2>Requirements</h2>

<ul>
<li>Python 3.10 or later</li>
<li>Poetry for installing the project’s dependencies</li>
</ul>
<h2>Installation</h2>
<p>I’ll inspect the repository’s README and application entry points to identify the project’s documented usage and supported startup options.</p>

<h2>Usage</h2>

<p>Start the API server from the repository:</p>

<p><code>bash
poetry run start
</code></p>

<p>Use the API to add documents with <code>/upsert</code>, search for relevant documents with <code>/query</code>, and remove documents with <code>/delete</code>. The server exposes an interactive API reference at <code>/docs</code>.</p>
