# public-apis<h2>Description</h2>

<p>A collective list of free APIs for use in software and web development.</p>
<h2>Requirements</h2>

<p>The validation scripts require these Python packages:</p>

<ul>
<li><code>certifi==2021.10.8</code></li>
<li><code>charset-normalizer==2.0.10</code></li>
<li><code>idna==3.3</code></li>
<li><code>requests==2.27.1</code></li>
<li><code>urllib3==1.26.8</code></li>
</ul>
<p>I’ll inspect the repository’s setup files and existing documentation to identify the project’s documented installation steps.</p>

<h2>Installation</h2>

<p>Install the Python dependencies from the project directory:</p>

<p><code>bash
pip install -r requirements.txt
</code></p>
<p>I’ll inspect the repository’s top-level files and any project documentation or scripts that describe how to use it.</p>

<h2>Usage</h2>

<p>Use this repository as a catalog: browse the API entries by category, then choose an API based on its description, authentication requirements, HTTPS support, and CORS support. Consult the API’s own documentation for details on making requests.</p>
<h2>Contributing</h2>

<p>Please ensure your pull request adheres to the following guidelines:</p>

<ul>
<li>Search previous suggestions before making a new one, as yours may be a duplicate.</li>
<li>Make an individual pull request for each suggestion.</li>
<li>Use this format: <code>- [API Name](API URL) - Description</code></li>
<li>New categories or improvements to existing categorization are welcome.</li>
<li>Keep descriptions short and simple, but descriptive.</li>
<li>Check your spelling and grammar, and remove trailing whitespace.</li>
<li>Give your pull request a descriptive title.</li>
</ul>
