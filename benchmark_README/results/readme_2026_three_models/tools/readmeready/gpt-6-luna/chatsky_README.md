# chatsky<h2>Description</h2>

<p>Chatsky is a Python framework for building conversational services. It represents dialog logic as a graph, providing a structure for defining how a service processes messages and moves between parts of a conversation.</p>
<h2>Requirements</h2>

<p>Chatsky requires <code>httpx</code> version <code>&gt;=0.27,&lt;1.0</code>.</p>

<p>The optional <code>all</code> extra adds support for additional integrations, including <code>aiolimiter</code>, <code>apscheduler</code>, <code>cachetools</code>, <code>cryptography</code>, <code>pytz</code>, and <code>tornado</code>. It also enables the <code>http2</code> and <code>socks</code> extras for <code>httpx</code>.</p>
<h2>Installation</h2>

<p>Install Chatsky from PyPI:</p>

<p><code>bash
pip install chatsky
