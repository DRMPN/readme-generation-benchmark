# EIPs<h2>Description</h2>

<p>This repository contains Ethereum Improvement Proposals (EIPs): documents that describe proposed changes, standards, and processes for Ethereum. They provide a basis for developers and the community to review and discuss those proposals.</p>

<h2>Usage</h2>

<p>This repository is a collection of Ethereum Improvement Proposals, rather than a software package to install or run. Browse the proposal documents in <code>EIPS/</code> and refer to a proposal by its EIP number. For information on the proposal format and process, see <code>EIPS/eip-1.md</code>.</p>
