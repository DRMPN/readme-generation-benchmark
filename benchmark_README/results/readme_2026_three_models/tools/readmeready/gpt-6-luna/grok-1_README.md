<h2>Description</h2>

<p>Grok-1 is an open-weight language model implemented in JAX. It uses a Mixture-of-Experts architecture with 314 billion total parameters. This repository contains the model code and utilities for running text generation with the model. The released model is a base model, not an instruction-tuned model.</p>
