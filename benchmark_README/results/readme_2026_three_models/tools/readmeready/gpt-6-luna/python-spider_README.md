# python-spider<h2>Description</h2>

<p><code>python-spider</code> includes a command-line tool for configuring comment display on a stage. You can set the stage dimensions, font and font size, text opacity, and how long comments are displayed. An output file can also be specified.</p>
<h2>Requirements</h2>

<p>Install the following Python packages:</p>

<ul>
<li><code>lxml==4.6.3</code></li>
<li><code>requests==2.20.0</code></li>
<li><code>Pillow&gt;=6.2.2</code></li>
<li><code>beautifulsoup4==4.6.0</code></li>
</ul>
<h2>Installation</h2>

<p>Install the project’s listed dependencies with pip:</p>

<p><code>bash
pip install lxml==4.6.3 requests==2.20.0 "Pillow&gt;=6.2.2" beautifulsoup4==4.6.0
</code></p>
