# Python-Weather-Info-App<h2>Description</h2>

<p>Python-Weather-Info-App is a desktop weather application built with Tkinter. It displays weather information for a default city (New Delhi) when it starts and provides a search interface for looking up another city using the OpenWeatherMap weather API.</p>

<p>The app includes configurable display settings, such as the background image, text colors, borders, and search button styling.</p>
<h2>Requirements</h2>

<ul>
<li>A Python runtime.</li>
<li>Internet access to query the OpenWeatherMap weather API.</li>
<li>The app’s configured OpenWeatherMap API key must be valid.</li>
<li>The image assets referenced by the app must be available: <code>assets/background.png</code> and <code>assets/search_icon.png</code>.</li>
</ul>
<h2>Installation</h2>
<h2>Usage</h2>

<p>Start the application to open the weather window. It displays weather information for <strong>New Delhi</strong> by default. Enter a city in the search bar and use the search button to look up its weather.</p>

<p>The app uses OpenWeatherMap. Set <code>API_KEY</code> in the application’s configuration to a valid API key before running it. The default city can be changed with <code>DEFAULT_CITY</code>.</p>
