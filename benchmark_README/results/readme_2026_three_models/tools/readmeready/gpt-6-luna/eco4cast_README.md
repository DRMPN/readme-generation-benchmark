<h2>Usage</h2>

<p>Before getting started:</p>

<ul>
<li>Create an ElectricityMaps account to monitor VM energy consumption and CO₂ emissions.</li>
<li>Have terminal access with SSH installed so you can connect to the VMs.</li>
<li>Use a machine in one of the supported zones listed below.</li>
</ul>

<h3>Set up the master machine</h3>

<p>The tutorial uses Google Colab as the master machine for controlling the VMs. In Colab, a virtual environment is not needed.</p>

<h3>Set up a machine</h3>

<p>For a machine outside Colab, create a virtual environment and install the required dependencies before using it.</p>
