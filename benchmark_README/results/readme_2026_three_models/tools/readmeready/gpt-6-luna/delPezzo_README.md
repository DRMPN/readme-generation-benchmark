# delPezzo<p>I’ll inspect the repository’s README and core modules to summarize what the project does and how its main pieces fit together.</p>

<h2>Description</h2>

<p>delPezzo is a SageMath module for studying the flexibility of affine cones over del Pezzo surfaces. It provides representations of surfaces, curves, points, and contractions, along with tools for working with cylinders and cone coverings. It also includes cone subdivision utilities and functions for generating surfaces from Lubbes data.</p>
<h2>Requirements</h2>

<ul>
<li>Python 3.9 or later.</li>
<li>SageMath, which the project uses for its del Pezzo surface computations.</li>
</ul>
<h2>Installation</h2>
