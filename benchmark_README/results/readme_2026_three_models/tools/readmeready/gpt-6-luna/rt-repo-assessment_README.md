<h3>Install</h3>

<p>From the repository root, create and activate a virtual environment, then install the project and its declared dependencies:</p>

<p><code>bash
python3.12 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install .
</code></p>

<p>Project dependencies are declared in <code>pyproject.toml</code>. The optional development dependency group includes <code>mypy</code>.</p>
