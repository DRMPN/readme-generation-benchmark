# devika<p>~~~</p>

<h2>Description</h2>

<p>Devika is an AI software engineering agent designed to turn high-level instructions into software tasks. It can plan work, research information, generate code, and help debug implementations.
~~~</p>

<h2>Requirements</h2>

<ul>
<li>Python 3.10 or later</li>
<li>Node.js and npm</li>
<li>Git</li>
<li>API credentials for a supported language model provider
~~~</li>
</ul>

```md</p>
<h2>Installation</h2>

<p>Install the Python dependencies from the repository root:</p>

<p><code>bash
pip install -r requirements.txt
</code></p>

<p>Install the frontend dependencies:</p>

<p><code>bash
cd ui
npm install
cd ..
</code>
```
~~~</p>
<p>~~~</p>

<h2>Usage</h2>

<p>Start Devika from the repository root:</p>

<p><code>bash
python devika.py
</code></p>

<p>Open the web interface at <a href="http://localhost:3000">http://localhost:3000</a>. Select or create a project, enter a task, and submit it to start working with Devika.
~~~</p>
