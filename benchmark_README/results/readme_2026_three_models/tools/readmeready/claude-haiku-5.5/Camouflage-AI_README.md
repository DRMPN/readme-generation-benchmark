# Camouflage-AI<h2>Description</h2>

<p>Camouflage-AI is an AI-powered desktop tool for removing video backgrounds using YOLOv8 segmentation.</p>

<p>It is built for Windows and requires Python 3.8 or later. It is released under the MIT License.</p>
<h2>Requirements</h2>

<ul>
<li>Python 3.8 or later (<code>python_requires='&gt;=3.8'</code>)</li>
<li>The package metadata lists Microsoft Windows (Win32) as the target environment.</li>
</ul>
<h2>Installation</h2>

<p>Camouflage-AI requires <strong>Python 3.8 or later</strong>.</p>

<p>Install the required dependencies with pip:</p>

<p><code>bash
pip install customtkinter
pip install opencv-python
pip install numpy
pip install rembg
pip install pillow
pip install moviepy
pip install matplotlib
pip install scikit-image
pip install tqdm
pip install pyperclip
</code></p>
