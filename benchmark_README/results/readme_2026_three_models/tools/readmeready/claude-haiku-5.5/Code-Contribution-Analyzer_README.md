# Code-Contribution-Analyzer<h2>Description</h2>

<p>Code Contribution Analyzer helps developers analyze their coding contributions across GitHub, GitLab, and Bitbucket, with in-depth metrics and reports.</p>

<h3>Features</h3>

<ul>
<li>Fetch contributions from GitHub, GitLab, and Bitbucket</li>
<li>Analyze the number of lines per language</li>
<li>Generate reports in various formats</li>
<li>Interactive data visualization</li>
</ul>

<h3>How to Use</h3>

<p>Authenticate with your repositories, and the tool will analyze your contributions.</p>
