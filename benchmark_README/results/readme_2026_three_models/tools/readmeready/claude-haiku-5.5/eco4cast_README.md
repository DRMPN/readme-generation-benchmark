<h2>Usage</h2>

<p>Before you start, you need:</p>

<ul>
<li><strong>ElectricityMaps account:</strong> Sign up for an ElectricityMaps account. It is used to monitor and manage the energy consumption and CO2 emissions of the VMs.</li>
<li><strong>Master machine:</strong> The tutorial uses Google Colab as the master machine to control the VMs. On Colab, you don't need a virtual environment (venv), so you can run the setup code directly.</li>
<li><strong>SSH and terminal access:</strong> You need a terminal with SSH installed to interact with the VMs.</li>
</ul>

<p><strong>Setup steps</strong></p>

<ol>
<li><strong>Set up the master machine.</strong> On Colab, run the setup code without creating a venv. If you use a local machine instead, create a venv and install the necessary dependencies.</li>
<li><strong>Choose a supported zone.</strong> The VM must be located in one of the supported zones:
<ul>
<li><code>BR-CS</code> (Central Brazil)</li>
<li><code>CA-ON</code> (Canada Ontario)</li>
<li><code>CH</code> (Switzerland)</li>
<li><code>DE</code> (Germany)</li>
<li><code>PL</code> (Poland)</li>
<li><code>BE</code> (Belgium)</li>
<li><code>IT-NO</code> (North Italy)</li>
