# devops-exercises<h2>Description</h2>

<p>This project contains DevOps exercise files. The provided configuration includes:</p>

<ul>
<li><strong>Kubernetes Deployment:</strong> A manifest (<code>apps/v1</code>, kind <code>Deployment</code>) named <code>nginx-deployment</code>. It runs 3 replicas of an <code>nginx</code> container using the image <code>nginx:1.14.2</code>, and it exposes container port 80. Pods are labeled <code>app: nginx</code>, and the Deployment's selector matches that label.</li>
<li><strong>Terraform configuration:</strong> Requires Terraform <code>&gt;= 1.3.0</code> and the <code>hashicorp/google</code> provider, version <code>&gt;= 4.10.0, &lt; 5.0</code>.</li>
</ul>
<h2>Requirements</h2>

<ul>
<li><strong>Terraform</strong> <code>&gt;= 1.3.0</code></li>
<li><strong>Google Cloud provider</strong> (<code>hashicorp/google</code>) version <code>&gt;= 4.10.0, &lt; 5.0</code></li>
</ul>
