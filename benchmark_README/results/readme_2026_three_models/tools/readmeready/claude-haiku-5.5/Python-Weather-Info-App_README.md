# Python-Weather-Info-App<h2>Description</h2>

<p>Python-Weather-Info-App is a small desktop weather application built with Python and Tkinter. When it starts, it displays weather information for a default city (New Delhi), and users can search for other cities using a search bar in the window. Weather data is retrieved from the OpenWeatherMap API.</p>

<p>The app's appearance and behavior are controlled by configuration values defined at the top of the main script, so you can adjust them without changing the layout code:</p>

<ul>
<li><strong>Default city:</strong> the city shown when the app launches.</li>
<li><strong>API settings:</strong> the OpenWeatherMap API key and base request URL.</li>
<li><strong>Weather info box:</strong> text color and border thickness.</li>
<li><strong>Header:</strong> font size, text color, and border thickness.</li>
<li><strong>Search bar:</strong> border color, and the color of the search button and its text.</li>
<li><strong>Images:</strong> paths to the background image and the search button icon.</li>
</ul>

<p>The window also includes a footer label with credit text at the bottom.</p>

<h2>Usage</h2>

<ol>
<li>Run the main Python script to start the application. This opens a desktop window built with Tkinter.</li>
<li>When the app starts, it shows the weather information for the default city, which is set to <code>New Delhi</code>.</li>
<li>To check another location, type a city name into the search bar and click the search button. The weather information box updates with the results.</li>
</ol>

<h3>Customization</h3>

<p>The settings at the top of the script can be changed to suit your needs:</p>

<ul>
<li><strong><code>DEFAULT_CITY</code></strong>: The city shown when the app starts.</li>
<li><strong><code>API_KEY</code></strong>: Your OpenWeatherMap API key. The script includes a key, but you can replace it with your own.</li>
<li><strong>Header, search bar, and weather info box settings</strong>: Text size, colors, and border thickness.</li>
<li><strong><code>DEFAULT_BACKGROUND_IMAGE</code> and <code>SEARCH_ICON_IMAGE</code></strong>: Paths to the background and search button icon images in the <code>assets</code> folder.</li>
</ul>
