# system-design-primer<h2>Description</h2>

<p>This section of the project contains Jupyter notebooks that walk through object-oriented design problems. Each notebook follows the same structure:</p>

<ul>
<li><strong>Constraints and assumptions:</strong> questions to ask the interviewer and the answers used to scope the problem.</li>
<li><strong>Solution:</strong> Python code that implements the design.</li>
</ul>

<p>The notebooks in this context cover these problems:</p>

<ul>
<li><strong>Design an LRU cache:</strong> a cache for web query results that evicts the least recently used entries.</li>
<li><strong>Design an online chat:</strong> text conversations, user management, friend requests, and group chats.</li>
<li><strong>Design a deck of cards:</strong> a generic 52-card deck with four suits, which is then extended to support games such as Black Jack.</li>
</ul>

<p>The notebooks were prepared by <a href="https://github.com/donnemartin">Donne Martin</a>. Source and license information is available on <a href="https://github.com/donnemartin/system-design-primer">GitHub</a>.</p>
