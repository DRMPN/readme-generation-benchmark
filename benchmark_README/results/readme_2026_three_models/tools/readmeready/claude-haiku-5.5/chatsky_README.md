# chatsky<h2>Description</h2>

<p>Chatsky is a Python framework for building chatbots and other conversational services. It supports Python 3.9 through 3.12 and is distributed as a library. The <a href="https://deeppavlov.github.io/chatsky/">documentation</a> covers installation, usage, and the API.</p>

<p>The project's documentation is organized into three parts:</p>

<ul>
<li><strong>Getting started</strong> introduces installing and using the library, along with the basic terms behind the framework.</li>
<li><strong>User guides</strong> explain how a conversational service should be set up and how it should function. They cover topics that the API reference does not, such as deployment and optimization.</li>
<li><strong>Tutorials</strong> provide hands-on guidance.</li>
</ul>

<p>For development, see the following:</p>

<ul>
<li><strong>Contribution rules</strong> are in <a href="CONTRIBUTING.md">CONTRIBUTING.md</a>. They describe how to contribute code, manage your workflow, and use tests.</li>
<li><strong>Project roadmap</strong> is on the <a href="https://github.com/deeppavlov/chatsky/milestones">GitHub milestones page</a>. It outlines planned features and enhancements.</li>
<li><strong>Release notes</strong> are on the <a href="https://github.com/deeppavlov/chatsky/releases">GitHub releases page</a>. They list new features, improvements, and bug fixes in each release.</li>
</ul>
