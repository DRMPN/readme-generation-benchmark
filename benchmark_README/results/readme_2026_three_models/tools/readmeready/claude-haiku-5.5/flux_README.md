<h2>Installation</h2>

<p>Flux is packaged with setuptools, so you can install it from a local clone of the repository with pip:</p>

<p><code>bash
git clone &lt;repository-url&gt;
cd flux
pip install .
</code></p>

<p>After installation, the <code>flux</code> command is available in your shell. It runs the <code>app</code> object from <code>flux.cli</code>.</p>

<p>The package version is derived from git tags using <code>setuptools_scm</code>, so install from a git checkout rather than an archive without version metadata.</p>
