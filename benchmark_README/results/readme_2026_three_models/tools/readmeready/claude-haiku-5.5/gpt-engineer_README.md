# gpt-engineer<h2>Description</h2>

<p>gpt-engineer is a tool that uses an AI model to generate a software project from a prompt. The context describes these capabilities:</p>

<ul>
<li><strong>Generating from a prompt:</strong> The user supplies a prompt, either directly or from a text file, and the model generates a response for it.</li>
<li><strong>Choosing a model:</strong> The model and its temperature setting (which controls response randomness) can be configured.</li>
<li><strong>Improving an existing project:</strong> An <code>improve_mode</code> option lets the tool work on a project that already exists.</li>
<li><strong>Clarifying specifications:</strong> A <code>clarify_mode</code> option lets the user discuss specifications with the AI before implementation begins.</li>
<li><strong>Self-healing:</strong> A <code>self_heal_mode</code> option enables the tool to attempt to correct its own output.</li>
<li><strong>Custom preprompts:</strong> Users can supply their own preprompts instead of the defaults.</li>
<li><strong>Entrypoint requirements:</strong> A separate text file can specify requirements for the project's entrypoint.</li>
<li><strong>Lite mode:</strong> A <code>lite_mode</code> option runs the tool in a lighter configuration.</li>
<li><strong>Azure OpenAI:</strong> An Azure OpenAI endpoint can be used as the AI service.</li>
</ul>

<p>The context also includes a <code>DiskMemory</code> component for storing and retrieving data, and a <code>Review</code> component for recording human feedback on the model's responses.</p>
