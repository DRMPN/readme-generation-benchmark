# MiniGPT-4<h2>Description</h2>

<p>This part of the repository contains code related to MiniGPT-4, a project for working with images and text. The provided code includes:</p>

<ul>
<li><strong>Image description instructions:</strong> A pool of prompts for briefly describing an image, such as "Briefly describe this image." and "A short image caption:". These are used to pair images with short descriptive instructions.</li>
<li><strong>Dataset configuration:</strong> A configuration entry for the <code>unnatural_instruction</code> dataset, a text-type dataset that points to a JSON annotation file of filtered instructions.</li>
