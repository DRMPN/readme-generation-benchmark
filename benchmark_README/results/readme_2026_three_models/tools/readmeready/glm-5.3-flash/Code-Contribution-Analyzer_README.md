# Code-Contribution-Analyzer<h2>Description</h2>

<p>Code-Contribution-Analyzer is a tool for analyzing your coding contributions across GitHub, GitLab, and Bitbucket. It fetches your contributions from these platforms, computes metrics such as the number of lines written per programming language, and generates reports in various formats with interactive data visualization.</p>

<p>Simply authenticate with your repositories and let the tool analyze your contributions.</p>

<h2>Usage</h2>

<p>Simply authenticate with your repositories and let the tool analyze your contributions.</p>

<ol>
<li>Provide your access token for the platform you want to analyze (GitHub, GitLab, or Bitbucket).</li>
<li>Fetch your repositories and their contributors.</li>
<li>Generate reports showing metrics such as lines of code per language, with interactive data visualization.</li>
</ol>
