# 30 Days Of Python

**30 Days Of Python** is a step-by-step Python programming challenge created by [Asabeneh Yetayeh](https://www.linkedin.com/in/asabeneh/) (Second Edition, July 2021). The repository breaks learning Python into 30 daily lessons, starting from your first "Hello, World!" script and finishing with web development, APIs, and databases. Every lesson is a self-contained Markdown tutorial with runnable examples, annotated screenshots, and graduated exercises, plus Python scripts and datasets you can practice with.

## Overview

The challenge is designed for beginners but also useful as a refresher. Lessons build on each other: core language features come first (variables, operators, data structures, control flow, functions), followed by intermediate topics (modules, comprehensions, error handling, files, dates), and finally applied topics such as statistics, data analysis, web scraping, web development with Flask, MongoDB, and building APIs. Each day ends with **💻 Exercises** organized into Level 1, Level 2, and Level 3 so you can measure your progress.

## Getting Started

### Prerequisites

- **Python 3** — the lessons use f-strings (Python 3.6+) and the recorded shell examples use Python 3.9.
- **pip** — used from Day 20 onward to install third-party packages.
- **Anaconda / Jupyter Notebook (optional)** — recommended from Day 24 onward for the statistics, NumPy, and pandas material.

### Setup

1. Clone the repository:

   ```sh
   git clone https://github.com/Asabeneh/30-Days-Of-Python.git
   cd 30-Days-Of-Python
   ```

2. (Recommended, covered in Day 23) create and activate a virtual environment:

   ```sh
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   ```

3. Install the packages used by the later lessons:

   ```sh
   pip install numpy pandas matplotlib seaborn scipy
   ```

   The NumPy lesson itself demonstrates `pip install numpy`, and its examples also import `matplotlib`, `seaborn`, and `scipy`.

## Usage

1. Open the current day's folder and read the Markdown lesson (for example, `04_Day_Strings/04_strings.md`). Lessons include a table of contents, code samples with expected output, and navigation links (`<< Day N` / `Day N+2 >>`) between days.
2. Run the example scripts as you read:

   ```sh
   python 01_Day_Introduction/helloworld.py
   python 02_Day_Variables_builtin_functions/variables.py
   python 12_Day_Modules/main.py
   ```

3. Complete the exercises. As the Day 2 instructions show, the intended workflow is to create your own `day_N` folder inside the project and write your solution files there (e.g., `day_2/variables.py`). Several exercises also reference the Python interactive shell (`help('keywords')`, `dir()`, `math`, `random`, etc.) and the datasets in `data/`.
4. Days 12 and 20 illustrate importing your own code: `mymodule.py` at the repository root and the `mypackage/` package (`arithmetics.py`, `greet.py`) demonstrate `import` and `from ... import ... as ...` patterns.

## Example Web Application (`python_for_web/`)

The final section of the challenge includes a working Flask application that ties together templates, routing, forms, and static files.

```sh
cd python_for_web
pip install -r requirements.txt
python app.py
```

`requirements.txt` pins the web stack (Flask 1.1.1 with Jinja2, Werkzeug, Click, itsdangerous, and MarkupSafe).

**Routes:**

| Route | Method | Purpose |
|-------|--------|---------|
| `/` | GET | Home page listing the technologies used (HTML, CSS, Flask, Python) |
| `/about` | GET | About page |
| `/post` | GET, POST | "Text Analyzer" form that accepts posted content |
| `/result` | GET | Result page shown after a form submission |

Templates live in `templates/` (`layout.html`, `home.html`, `about.html`, `post.html`, `result.html`) and stylesheets in `static/css/main.css`. The app disables static-file caching in development, and `Procfile` is included so the app can be deployed to a platform that reads it. The server binds to `0.0.0.0` and uses the `PORT` environment variable when present:

```sh
PORT=8080 python app.py   # defaults to 5000 if PORT is not set
```

Day 27's MongoDB material uses MongoDB Atlas (registration, free cluster creation, network access, and obtaining a connection URI for the Python driver — illustrated by the screenshots in `images/mongoDB/`).

## Configuration

- The Flask app reads `PORT` from the environment and runs with `debug=True`; static-file caching is disabled via `SEND_FILE_MAX_AGE_DEFAULT = 0`.
- Day 23 explains creating and activating Python virtual environments, which is the recommended way to isolate the packages used by the later lessons.
- Third-party packages (NumPy, pandas, Flask, plotting libraries) are installed with `pip`, as demonstrated in the Day 20 and Day 24 lessons.

## Development Notes

- Lessons follow a consistent format: a centered header with the author's LinkedIn/Twitter badges, the edition date, a banner image, an anchored table of contents, the day's material, exercises at three levels, and navigation links to the previous and next days.
- `old_files/` preserves the original per-day readme segments (e.g., `readme4-6.md`, `readme28-30.md`) from earlier editions of the challenge.
- `test_files/` contains the plot images (`test_121_0.png`, `test_141_0.png`, `test_143_0.png`) produced by the Matplotlib/Seaborn examples embedded in `numpy.md`.

## Testing

This repository is a learning curriculum rather than a software product, so it does not include an automated test suite. Verification is done by:

- Running the provided example scripts and comparing their output against the expected results printed in the lessons.
- Completing the levelled exercises and checking your solutions against the sample outputs shown in each lesson (e.g., the triangle pattern in Day 10 or the formatting tables in Day 4).
