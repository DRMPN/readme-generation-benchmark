# Comprehensive Python Cheatsheet

A single-page, syntax-highlighted Python cheatsheet served as a static website. The project generates `index.html` from a Markdown source document and an HTML template using a Node.js build script, and ships with everything needed to also produce a print-ready PDF version of the cheatsheet. The document is authored by Jure Šorn.

## Overview

The cheatsheet is organized into eight top-level sections, as reflected in the table of contents generated by the build script:

1. **Collections** — List, Dictionary, Set, Tuple, Range, Enumerate, Iterator, Generator
2. **Types** — Type, String, Regular_Exp, Format, Numbers, Combinatorics, Datetime
3. **Syntax** — Function, Inline, Import, Decorator, Class, Duck_Type, Enum, Except
4. **System** — Exit, Print, Input, Command_Line_Arguments, Open, Path, OS_Commands
5. **Data** — JSON, Pickle, CSV, SQLite, Bytes, Struct, Array, Memory_View, Deque
6. **Advanced** — Operator, Match_Stmt, Logging, Introspection, Threading, Coroutines
7. **Libraries** — Progress_Bar, Plot, Table, Console_App, GUI, Scraping, Web, Profile
8. **Multimedia** — NumPy, Image, Animation, Audio, Synthesizer, Pygame, Pandas, Plotly

The rendered page uses syntax highlighting (highlight.js) for code blocks, and code examples are presented in the style of a runnable script (including `>>>` REPL-style examples and `$ pip3 install ...` instructions in comments).

## Setup

The build script is written in JavaScript because this code used to be executed on the client side.

1. Install Node.js and npm:

   ```bash
   $ sudo apt install nodejs npm   # On macOS use `brew install ...` instead.
   ```

2. Install the required dependencies globally:

   ```bash
   $ npm install -g jsdom jquery showdown highlightjs@9.12.0
   ```

3. If running on macOS and modules cannot be found after installation, add the following to your `~/.bash_profile` or `~/.bashrc` and run `$ bash`:

   ```bash
   export NODE_PATH=/usr/local/lib/node_modules
   ```

To avoid problems with permissions and path variables, you can instead install the modules into the project's directory:

```bash
$ npm install jsdom jquery showdown highlightjs@9.12.0
```

## Usage

Generate the site with:

```bash
$ node parse.js
```

`parse.js` creates `index.html` out of `web/template.html` and the Markdown source (README). The script performs all Markdown conversion and syntax highlighting at build time, so the deployed site is fully static and does not need to convert anything in the browser.

### PDF generation

The `pdf/README.md` file contains detailed, step-by-step instructions (written for macOS) for producing a PDF version of the cheatsheet. In summary, the workflow is:

* **Normal (screen) PDF** — Prepares `index.html` by swapping in the index/footer from `pdf/index_for_pdf.html`, opens the page in a specific Chromium version (108.0.5328.0; later versions render the site incorrectly after the index is added) with the cache disabled, tweaks body margins and the brightness of comments/text via the inspector, and prints to PDF on A4 with custom margins (the resulting document is 51 pages long, with the last page empty). Plots are then verified for correct rendering.
* **PDF optimized for laser color printing** — Runs `./parse.js` again, then uses `./pdf/remove_links.py` to convert links in the text to plain text with page numbers in brackets (e.g., `(p. <page_num>)`, links can be found with the regex `<strong>.*a href.*</strong>`). It swaps in `pdf/index_for_pdf_print.html` and adjusts the lightness of many specific elements (text, code-sidebar line, hash characters, red/blue text, decorators, `>>>` markers, comments) in the inspector before printing.
* **Headers and footers** — Applied in Adobe Acrobat Pro DC using the presets stored in `pdf/acrobat/` (copied to `~/Library/Preferences/Adobe/Acrobat/DC/HeaderFooter/`). The process includes cropping pages, applying each saved preset (`bottom_line`, even/odd pages, chapters), and, if presets are lost, manually re-entering the font and margin values documented in the PDF instructions (font Menlo, size 8, and specific border/offset values). The document title is set to "Comprehensive Python Cheatsheet" and the author to "Jure Šorn". A "Save as" in "Adobe PDF Files, Optimized" format fixes the Menlo font encoding error that Acrobat reports.
* **Compressing** — The two PDF files are zipped together with a `HOW_TO_PRINT.txt` instructions file:

  ```bash
  $ zip 'Comprehensive Python Cheatsheet.zip' 'Comprehensive Python Cheatsheet.pdf' \
        'Comprehensive Python Cheatsheet (optimized for printing).pdf' 'HOW_TO_PRINT.txt'
  ```
* **Printing the PDF** — Open the print-optimized PDF in Chrome and print on A4, both sides, with default margins, scale 98%, and no headers and footers.

## Configuration

There is no external configuration file. Behavior is controlled by editing the sources directly:

* **Content** — Edit the Markdown source document and re-run `node parse.js` to regenerate `index.html`. Do not edit `index.html` directly; it is a build artifact.
* **Layout** — `web/template.html` holds the page skeleton; `web/style.css` is the main stylesheet, with several alternate dark themes (`web/style_dark.css`, `web/style_dark1.css` … `web/style_dark3.css`) and highlight.js themes (`default.min.css`, `default_dark*.min.css`).
* **Assets** — Images, favicon, and social preview images live in `web/`.

## Development

* After changing the Markdown source or template, always re-run `node parse.js` so `index.html` is rebuilt.
* The build script's header comments recommend adding a Git pre-commit hook that regenerates the site before every commit. Create `.git/hooks/pre-commit` (executable) containing:

  ```bash
  ./parse.js
  ```

* Helper Python scripts in `web/` and `pdf/` (`convert_table.py`, `update_plots.py`, `empty_script.py`, `create_index.py`, `remove_links.py`) are used to maintain auxiliary assets such as the COVID-19 data files (`covid_cases.js`, `covid_deaths.js`), the `continents.csv` data, and the PDF-specific index/footer files.
* Client-side libraries are vendored into `web/`: jQuery 3.4.0 (full and slim builds), highlight.js 9.12.0, showdown, and Plotly. The Menlo Regular and Menlo Bold web fonts are also vendored, each with its own `License.txt` from OnlineWebFonts (highlight.js is distributed under the BSD 3-Clause license).

## Testing

The repository contains no automated test suite. Verification is manual:

* Rebuild `index.html` and open it in a browser to confirm the content, table of contents links, syntax highlighting, and plots render correctly.
* When producing a PDF, the instructions require explicitly checking that plots were rendered correctly, that the bottom line of the first page aligns properly with the text, and that the output is 51 pages long with the last page empty.
