# delPezzo

**delPezzo** is a SageMath module for studying flexibility of affine cones over del Pezzo surfaces (version 2025.1, author: Alexander Perepechko, a@perep.ru).

The module represents (possibly weak) del Pezzo surfaces combinatorially in the Picard lattice, constructs cylinders on them, and verifies — by covering the ample cone with polarity domains of cylinders — that the affine cone over the surface is generically flexible. The approach is described in [Pe23] (see [References](#references)).

## Features

- **`Surface`** — a generic (weak) del Pezzo surface of degree 1–9, given as a blowup of `P^2` with optional **`WeakDependencies`** of the blown-up points (collinear triples, chains of infinitely near points, six points on a conic, cuspidal cubics). Computes the Picard lattice, all `(-1)`- and `(-2)`-curves, the singularity (ADE root) type, iterates `blowups()`, lists contractions to `P^2` (`contractions_P2()`), and enumerates pairwise disjoint subsets of curves.
- **`Contraction`** — a contraction of a set of `(-1)`/`(-2)`-curves to `P^2`: chains of contracted curves, projections, and the line and conic classes (with dimensions of the corresponding linear systems).
- **`Cylinder` / `CylinderList`** — algebraic cylinders on a surface, recorded by the `(-1)`-curves in their support and complement, generic fiber, base point and transversality. Supported constructions: `'lines'`, `'lines2'`, `'tangent'`, `'P1xP1'`, `'cuspcubic'` (generic surfaces), and `'LL'`, `'QT'` (suitable for weak surfaces). Collections provide polarity (`Pol`, `is_polar_on`, `get_polar_on`), reduction (`reduce`), completeness (`is_complete_on`), transversality and the combined check `is_generically_flexible_on`.
- **`NE_SubdivisionCone`** — the Mori (NE) cone generated by negative curves together with its subdivisions. Cones are classified by Fujita-type names (`NE`, `B(i)`, `C(i)`, with `-P1xP1` variants); one can iterate `children()`/`ample_children()` and obtain representatives by type. Helpers `relint_contains_relint` and `relints_intersect` compare cones via relative interiors.
- **`Finder`** — automated search for cylinder coverings of the NE cone: starting from the whole cone, it subdivides cones on which generic flexibility is not yet certified (`iterate()`) and reports the resulting `ConeCovering`s.
- **`Lubbes_parse`** — reads the bundled `Lubbes_list.txt`, a table of weak del Pezzo surfaces with singularity root types taken from Lubbes' work on minimal families of curves [Lub-min], [Lub-algo]. `generate_surfaces(degree)` yields `Surface` objects for a given degree; `generate_surface(line)` parses a single line.

## Requirements

- Python ≥ 3.9 (see `pyproject.toml`)
- [SageMath](https://www.sagemath.org/) — the code imports `sage` throughout (toric lattices, polyhedral cones, Cartan matrices, quadratic forms), so it must be run with SageMath's Python, e.g. `sage --python`.
- `pytest` for the test suite

A VS Code dev container based on the `sagemath/sagemath:latest` image is provided in `.devcontainer/devcontainer.json`; it installs `tqdm` and `pytest` via `sage --pip`.

## Installation

The package uses the standard `src` layout with a `pyproject.toml`. Install it into SageMath's Python environment:

```bash
sage --pip install .          # or: sage --pip install -e .
```

Alternatively, make it importable without installation:

```bash
PYTHONPATH=src sage --python
```

## Quick start

Build all cylinders of the given types on a degree 5 del Pezzo surface and check generic flexibility for all ample polarizations (as in `tests/test_deg5.py`):

```python
from delPezzo import Surface, CylinderGenerator, CylinderList

S = Surface(5)
cylinders = CylinderList(list(CylinderGenerator.all_cylinders(S, ['lines2'])))
assert cylinders.is_generically_flexible_on(S.Ample)
```

Search for coverings certifying generic flexibility for every polarization (as in `tests/test_finder.py`):

```python
from delPezzo import Finder, Surface

S = Surface(5)
F = Finder(S=S, constructions=['lines', 'lines2', 'tangent'])
F.iterate()                          # subdivide cones where flexibility is not yet certified
assert F.all_coverings_are_genflex()
```

Work with weak del Pezzo surfaces from Lubbes' list (as in `tests/test_Lubbes.py`):

```python
from delPezzo import generate_surface, generate_surfaces

S = generate_surface("18 5 [23, 45] 2A1")   # weak del Pezzo surface of degree 4, type 2A1
for S in generate_surfaces(4):
    print(S)
```

## Tests

The test suite lives in `tests/` and runs with `pytest` (options such as `--import-mode importlib` are preset in `pyproject.toml`). After installing the package (or with `PYTHONPATH=src`):

```bash
sage --pip install pytest
sage --python -m pytest tests/
```

Several test files reproduce coverings and cylinders from the literature cited below, e.g. [CPW15] for degree 2, [Pe13] for degree 5, and [Pe20] for degree 3.
