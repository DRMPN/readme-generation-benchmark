# Professional Programming

A collection of notes, examples, and learning resources about software development. The repository is organized as browsable Markdown documents, training materials, reference PDFs, and supporting images; it is not presented as an installable software package.

## Contents

### Topics and reference notes

- [Feature flags](feature-flags.md) — reasons to use flags, when they may or may not be appropriate, and references.
- [Glossary](glossary.md) — selected software and systems concepts.
- [Clean Code cheat sheet (PDF)](cheatsheets/Clean-Code-V2.4.pdf)
- [Clean Architecture cheat sheet (PDF)](cheatsheets/Clean-Architecture-V1.0.pdf)

### Anti-patterns

The [anti-patterns index](antipatterns/README.md) links to examples and discussion covering code, databases, error handling, MVCS, scalability, SQLAlchemy, and tests. Some sections are works in progress and contain TODOs.

### Training materials

- [Learning web development](training/web-dev/README.md) — an opinionated web-developer ramp-up outline, with learning principles, a roadmap, and topic-based resources.
- [Front-end programming for back-end developers](training/front-end/README.md) — introductory course notes intended to support an oral presentation. Its curriculum covers modern JavaScript, React, TypeScript, the browser, HTML/CSS, and front-end development practices.
- [Learning Python](training/learning-python/README.md) — points readers to the separate [charlax/python-education](https://github.com/charlax/python-education) repository.

The `images/` directory contains figures and other image assets used by the documents.

## Using the materials

Open the Markdown files in a viewer or read them directly in the repository. The PDFs in `cheatsheets/` are standalone reference sheets. No build or installation steps are documented for this collection.
