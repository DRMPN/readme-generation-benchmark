# 30 Days of Python

This repository contains the learning materials for a 30-day Python programming challenge. The lessons move from Python fundamentals to working with data, web development, MongoDB, and APIs. Most day folders contain a Markdown lesson with explanations, examples, and exercises; the first day includes a small Python script instead. Lesson pages credit Asabeneh Yetayeh and generally identify this as the second edition from July 2021.

## Getting started

The lessons use Python 3. To try the Day 1 example, install Python 3, open a terminal in the repository directory, and run:

```sh
python 01_Day_Introduction/helloworld.py
```

Depending on your system, the command may be `python3` instead of `python`. The lessons are intended to be followed in order, reading each Markdown file and working through its exercises. Some later topics use third-party tools or packages; follow the setup instructions in the relevant lesson before running those examples.

## Repository contents

- `01_Day_Introduction/` through `30_Day_Conclusions/` — the day-by-day lessons and examples.
- `data/` and `files/` — supporting data and sample files used by course material.
- `images/` — figures and screenshots referenced by the lessons.
- `mypackage/`, `numpy_files/`, and `python_for_web/` — additional examples and learning resources related to topics in the course.
- `Chinese/`, `Korean/`, `korean/`, and `Portuguese/` — translated lesson material. Coverage varies by language; these folders do not contain a complete translation of every day.
