## Overview

This is a research-oriented Python library for working with (weak) del Pezzo surfaces in algebraic geometry. It models Picard lattice classes, subdivisions of the Néron-Severi cone of effective curves (NE cone), and collections of cylinders on these surfaces. The library is intended for researchers in algebraic geometry and for users familiar with SageMath, which it depends on. Its functionality is exposed through Python classes and methods rather than a command-line, web, or machine learning interface. For installation and runnable steps, see the Getting Started section.

---

## Core Features

- **Surface models for (weak) del Pezzo surfaces:** Represents surfaces by degree in the Picard lattice, with optional blowup dependency data for weak surfaces. This gives researchers a computational object to work with directly.
- **Cylinder and cylinder-list objects:** Models cylinders on a surface, including line-based, conic-and-tangent, and P1xP1-based constructions, and groups them into collections. This lets you assemble and manipulate cylinder collections programmatically.
- **Cone subdivision of the curve cone:** Subdivides the cone generated by (-1)- and (-2)-curves and the line class into child cones, keeping track of each cone's creation history. This supports systematic exploration of regions of polarizations.
- **Finder and covering objects:** Searches for cylinder collections that cover polarization cones and records the result as a covering per cone. This automates the search for covering collections across subdivided cones.

## Getting Started

### Prerequisites

- **SageMath** is a hard dependency. The package imports `sage.all_cmdline`, `sage.matrix`, `sage.rings`, `sage.geometry`, `sage.combinat`, and `sage.quadratic_forms`, so run the code in an environment where these are available.
- **Python 3.10 or newer** is required. `src/delPezzo/cone.py` uses `match` statements.

### Quickstart

1. Make the `src/` directory available on the Python path. The package is located at `src/delPezzo/`.

2. Start a SageMath session and import the surface class:

```python
   from delPezzo.surface import Surface
```

3. Create a del Pezzo surface of degree 5:

```python
   S = Surface(5)
```

4. Run the search for cylinder coverings on the surface's cones:

```python
   from delPezzo.finder import Finder

   F = Finder(S)
   F.all_coverings_are_genflex()
```

The `Surface` degree must be an integer between 1 and 9, inclusive. Test files are located in `tests/`; the test runner is not specified in the repository.

## Testing

The test suite lives in the `tests/` directory. The following files are present:

- `tests/test_Lubbes.py`
- `tests/test_blowups.py`
- `tests/test_contraction.py`
- `tests/test_deg1.py`
- `tests/test_deg2.py`
- `tests/test_deg2_B2.py`
- `tests/test_deg2_KimPark.py`
- `tests/test_deg3.py`
- `tests/test_deg4.py`
- `tests/test_deg5.py`
- `tests/test_finder.py`
- `tests/test_surface.py`
- `tests/test_various.py`
- `tests/test_weak_deg6.py`
- `tests/tests.ipynb`

There is no `tests/test_cone.py` file, so the tests in `tests/` do not include a dedicated module for `src/delPezzo/cone.py`.

The test files are grouped by topic and surface degree rather than into separate unit, integration, or end-to-end folders.

The package modules import SageMath (for example, `from sage.all_cmdline import *`), so tests need a SageMath environment.

The exact test run command is not specified in the provided files. To find the test configuration, check `pyproject.toml`.
