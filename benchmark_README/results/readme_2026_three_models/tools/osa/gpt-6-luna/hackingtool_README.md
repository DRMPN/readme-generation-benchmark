## Overview

This project provides an interactive Python command-line application for organizing and operating a collection of security tools. It is intended for security practitioners and technically proficient users working in Linux environments; the application requests Debian for best results. Newcomers can use the Getting Started section for runnable steps and an introduction to the interactive menus.

---

## Installation

From the repository root, install the project dependencies:

```sh
pip install -r requirements.txt
```

---

## Getting Started

Prerequisites: Linux is supported; Debian is recommended for best results. Python dependencies are listed in `requirements.txt`.

1. From the project directory, install the dependencies:

```bash
pip3 install -r requirements.txt
```

2. Start the application:

```bash
python3 hackingtool.py
```
