## Overview

This Python-based tool assesses software repositories by scoring repository metadata and file contents against configured criteria, then producing JSON and Markdown reports. It is intended for developers and repository maintainers evaluating repository quality. See Getting Started for runnable steps and an introduction to the assessment workflow.

## Installation

**Prerequisites:** requires Python >=3.12,<4.0

Install rt-repo-assessment-yk8gkvzu using one of the following methods:

**Using the current local checkout:**

1. Open the repository root:
```sh
cd path/to/rt-repo-assessment-yk8gkvzu
```

2. Install the project in editable mode:

```sh
pip install -e .
```
