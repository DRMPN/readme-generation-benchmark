## Overview

Camouflage AI is a Python desktop application for removing or replacing video backgrounds through person segmentation. It is intended for desktop users who want to process videos with a graphical interface. The application combines video selection and background controls with a processing workflow, offering color, image, and blur backgrounds.

---

## Core Features

- Remove people from video backgrounds with person segmentation, making it possible to replace the original scene while retaining the foreground subject.
- Choose a solid color, an image, or a blurred version of the original scene as the replacement background to suit different video styles.
- Use the desktop interface to select a video, configure its background, and process it into an output video.
