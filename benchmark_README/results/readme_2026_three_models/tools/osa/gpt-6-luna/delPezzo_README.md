## Overview

delPezzo-pljuccqn is a Python library for computational geometry and algebraic geometry involving (weak) del Pezzo surfaces, with a focus on cylinder coverings and flexibility questions. It is intended for researchers and mathematically oriented developers working with these surfaces and related cone computations. The library provides computational representations of surfaces, curves, cones, and cylinders, along with tools for searching cylinder coverings.

---

## Core Features

- Model generic and weak del Pezzo surfaces with Picard-lattice curve classes and exceptional curves, providing a geometric basis for computations.
- Represent and subdivide cones of divisor classes to examine regions containing ample polarizations.
- Generate cylinder configurations from geometric constructions and organize them into collections for analysis.
- Search for cylinder coverings across polarization cones and assess generic flexibility to study coverage across polarizations.
