## Overview

This repository contains Ethereum Improvement Proposals (EIPs), design documents for proposing and documenting changes to Ethereum, its application standards, and its processes. It is intended for EIP authors and editors, Ethereum community members, and developers evaluating or implementing proposals. Proposal documents and process guidance help readers understand proposals and how they move through community review. Read [EIP-1](EIPS/eip-1.md) for process guidance, or browse the [proposal documents](EIPS/).
