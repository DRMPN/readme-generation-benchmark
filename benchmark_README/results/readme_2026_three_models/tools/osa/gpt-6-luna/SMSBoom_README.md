## Overview

SMSBoom sends HTTP requests to configured SMS-related APIs. It is intended for people operating the project through a command-line interface or a desktop graphical interface. Newcomers can use the Getting Started section for runnable steps.

---

## Installation

Install SMSBoom-04cega1u using one of the following methods:

**Using the current local checkout:**

1. Open the repository root:
```sh
cd path/to/SMSBoom-04cega1u
```

2. Install the project dependencies:

```sh
pip install -r requirements.txt
```

---

## Getting Started

The project provides a Python CLI (`smsboom.py`) and a Tkinter GUI (`smsboom_GUI.py`). Install the dependencies listed in `requirements.txt`; Tkinter is needed for the GUI.

The CLI loads `api.json` and `GETAPI.json` from the same directory as the script. The supplied context does not verify a launch command, so no run command is included.
