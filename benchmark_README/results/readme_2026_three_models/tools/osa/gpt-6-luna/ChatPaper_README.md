## Overview

ChatPaper provides AI-assisted tools for academic-paper workflows, including paper retrieval, PDF processing, translation, review, and survey generation. It is intended primarily for researchers and academic-paper readers, as well as developers working with these workflows. The repository offers separate tools and subprojects, including deployment applications, rather than a single unified application.
