## Overview

eco4cast is a Python project focused on reducing CO₂ emissions during neural-network training on Google Cloud. It is intended for developers and ML practitioners who train neural networks in that environment and want to account for training-related emissions. The project provides neural-network training workflows alongside Google Cloud Compute examples.
