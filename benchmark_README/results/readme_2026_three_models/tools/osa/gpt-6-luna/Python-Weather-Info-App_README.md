## Overview

This Python desktop application provides weather information for a searched city through a graphical interface. It is intended for people who want to check weather from a desktop app. See Getting Started for runnable steps.

---

## Core Features

- Look up weather for a city in a desktop interface, with search available by button or Enter key.
- View current conditions and details including temperature, pressure, humidity, wind speed, sunrise, and sunset.
- Customize the default city and interface appearance, including colors, text sizing, and images.
