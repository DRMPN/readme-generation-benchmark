## Overview

HTTPX is a Python HTTP client library for making requests to HTTP services. It is intended for developers building applications that communicate over HTTP, as well as users who want to send requests from the command line. The project offers synchronous and asynchronous client APIs alongside a command-line interface for making requests and viewing responses.
