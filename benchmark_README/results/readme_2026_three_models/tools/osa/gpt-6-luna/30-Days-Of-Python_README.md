## Overview

30 Days Of Python is an educational curriculum that guides learners through Python concepts over 30 days. It is aimed primarily at people learning Python, especially beginners, and later lessons also suit developers exploring web apps and APIs. The curriculum is organized as sequential lessons with explanations, code examples, and exercises, alongside a small Flask web-app example; see Getting Started for runnable steps.

---

## Installation

Use a local checkout of the repository. To run the Flask example, follow the steps in [Getting Started](#getting-started).

---

## Getting Started

The curriculum uses Python. To run the Flask example, install Flask in your environment and start the sample app:

1. Change to the app directory:
```sh
   cd python_for_web
```
2. Install Flask:
```sh
   pip install Flask
```
3. Run the app:
```sh
   python app.py
```
4. Open `http://localhost:5000` in your browser.
