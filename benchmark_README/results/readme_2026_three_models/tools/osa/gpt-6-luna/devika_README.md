## Overview

Devika is an AI-powered software development assistant designed to help developers create and work on software projects. Through a web interface, it supports project-focused workflows for planning, researching, coding, and running tasks. Newcomers can interact with the assistant through project conversations.

## Architecture

Devika has a modular Python backend paired with a separate Svelte web UI. The UI sends requests to the backend through HTTP APIs and socket-based messaging.

The backend routes development requests through agent components for tasks such as planning, research, coding, and execution. These components draw on LLM integrations and supporting browser, memory, and service modules. Project conversations and state are managed by the backend, with project data persisted in SQLite.
