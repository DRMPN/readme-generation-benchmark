## Overview

This repository contains the Ethereum Improvement Proposals (EIPs): a corpus of numbered specification documents that describe proposed standards, features, and processes for Ethereum. Each proposal is a Markdown document with structured metadata (including its number, title, status, type, and category), maintained in a versioned repository so its revision history records the evolution of each proposal. It is intended for EIP authors, editors, Ethereum client implementers, and community members who need to author, review, or track the status of proposals. Readers can browse individual proposal documents, follow the proposal lifecycle and types defined in the EIP-1 specification, and consult the Contributing guidance for how to participate.

---

## Core Features

- Canonical repository of Ethereum Improvement Proposals (EIPs): self-contained specification documents that define protocol changes, application standards, and processes for the Ethereum ecosystem.
- Each proposal carries structured front matter (number, title, status, type, category, author, created, dependencies), so readers can quickly identify what a proposal covers and where it stands in its lifecycle (e.g., Draft, Final, Living, Moved).
- The proposal process itself is formally specified, including EIP types (Standards Track, Meta, Informational), workflow stages, and the roles of authors, editors, and core developers — giving contributors a clear path for drafting and advancing proposals.
- Serves as the shared reference client implementers use to track which EIPs they have implemented, helping coordinate protocol upgrades and interoperability across the ecosystem.
- Application-level standards (ERCs) have been split into a separate repository, with stub entries here pointing to their current locations.
