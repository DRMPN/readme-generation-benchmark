## Overview

This repository is an educational reference collection of software engineering best practices, anti-patterns, and cheat sheets, with a primary focus on Python, SQLAlchemy, and PostgreSQL database design, and additional material on modern front-end development with JavaScript, React, and TypeScript. It is intended for developers—particularly those working on back-end or full-stack projects—who want to recognize common pitfalls and improve code quality. The content is organized as structured guides and training materials rather than a runnable application, covering topics such as code, SQLAlchemy, database, and error-handling anti-patterns, along with guided learning tracks. See the Getting Started section for how to begin reading and using this material.

## Getting Started

This repository serves as a collection of software engineering examples and anti-patterns across various technologies, rather than a single monolithic application. To run an example, you must first select the technology stack you wish to explore.

**Prerequisites**

*   **Python:** Required for all back-end examples, including SQLAlchemy patterns and exception handling tests.
*   **Node.js/npm:** Required for running front-end and JavaScript examples (React/TypeScript).

**Getting Started**

1.  **Clone the repository:**
```bash
git clone https://github.com/professional-programming-dg5vfzcw.git
```
2.  **Select an example:** Navigate to the appropriate directory based on your interest (e.g., `antipatterns/python-examples` for Python code, or `training/front-end` for HTML/JavaScript).
3.  **Execute/Review:** Run the specific file using the corresponding interpreter (e.g., `python reraise_exceptions_good.py`) or review the provided code snippets to understand the pattern or anti-pattern in context.
